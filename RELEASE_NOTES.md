First public work-in-progress beta of Monster Farm DS English by StepPhone of the StepHackerZ.

Download the ZIP and apply its BPS patch to a clean Japanese AFMJ ROM. Includes reviewed event dialogue, system/menu messages, item and trait descriptions, interface translations and layout fixes.

Known Japanese remains in tournament, wild-monster and ending tables, some overlay text and graphics. Encyclopedia text and some terminology still need review. This is not a complete English release.

BPS reconstruction and installed-resource checks pass. A complete campaign, physical hardware and wireless play remain untested. Restart after updating and load a normal in-game save.

No ROM, BIOS, emulator or save is included. See the repository README for checksums, instructions and limitations.
